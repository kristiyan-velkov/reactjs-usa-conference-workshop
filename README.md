# React USA Conference Workshop

Demo **React 19 + Vite** landing page for a front-end security workshop.

## Safe branch (`main`)

This branch contains only standard dependencies. You can install and run locally:

```bash
npm ci
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Workshop PR branch

A separate branch may add a **known malicious npm package** for supply-chain training. **Do not merge or run that branch without reading the PR warning.**
